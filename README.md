# MSc Dissertation Data Analysis Portfolio
# 硕士毕业论文数据分析作品集

## Overview | 项目简介

This repository presents the data-processing and statistical-analysis workflow developed for my MSc dissertation project using football event data.

The workflow uses **Python** for data cleaning, feature engineering, expected threat (xT) calculation, and quality assurance, followed by **R** for statistical modelling, sensitivity analysis, and data visualisation.

To protect the original research data, the event-level datasets included in this public repository are **synthetic demonstration data**. They are intended to demonstrate the analytical workflow only and do not reproduce the statistical findings of the original study.

本项目展示了本人硕士毕业论文中使用的足球事件数据处理与统计分析流程。

项目使用 **Python** 完成数据清洗、变量构建、Expected Threat（xT）计算及质量检查，并使用 **R** 完成统计建模、敏感性分析及数据可视化。

出于数据保密考虑，本公开仓库中的事件级数据均为**虚拟演示数据（synthetic data）**，仅用于展示分析流程，不代表或复现原研究的统计结果。


## Analysis Workflow | 分析流程

The overall workflow is:

**Synthetic event data → Python data processing → Processed pass-level dataset → R statistical analysis and visualisation**

整体分析流程为：

**虚拟事件数据 → Python 数据处理 → 传球级处理数据 → R 统计分析与可视化**


### `DataCleaning.ipynb`

Main Python notebook for the data-processing workflow.

主要的 Python 数据处理文件，包括：

- importing and merging match event files / 导入及合并比赛事件文件
- validation and file filtering / 文件筛选及基本检查
- data cleaning and variable construction / 数据清洗与变量构建
- calculation of expected threat (xT) / Expected Threat（xT）计算
- construction of pass zones, transitions, and score states / 构建传球区域、传球类型及比分状态等变量
- quality-assurance checks / 数据质量检查
- generation of the processed dataset used by the R analysis / 生成供 R 分析使用的处理后数据


### `backpack_function.py`

Contains reusable Python functions called by `DataCleaning.ipynb`.

包含 `DataCleaning.ipynb` 调用的可复用 Python 函数。


### `sample data/`

Contains synthetic event-level datasets created solely to demonstrate the workflow.

该文件夹包含仅用于展示分析流程的虚拟事件级数据。

`empty_file.csv` intentionally contains no event data and is included to demonstrate how the Python workflow handles and skips invalid or empty input files.

`empty_file.csv` 刻意设置为空文件，仅用于展示 Python 数据导入流程如何识别并跳过无效或空白文件。

`df_pass_sample.csv` is the processed synthetic pass-level dataset generated by the Python workflow. A copy is included in the repository so that the R analysis can also be run independently without first executing the Python notebook.

`df_pass_sample.csv` 是 Python 流程生成的处理后虚拟传球数据。本仓库同时提供该文件，以便使用者无需首先运行 Python，也可以直接运行 R 统计分析。


### `statistical analysis.Rmd`

R Markdown file containing the statistical-analysis workflow, including:

R Markdown 统计分析文件，包括：

- basic validation of imported analysis data / 导入数据的基本检查
- linear mixed-effects models (LMMs) / 线性混合效应模型
- generalised linear mixed-effects models (GLMMs) / 广义线性混合效应模型
- model comparison and diagnostics / 模型比较与诊断
- sensitivity analyses / 敏感性分析
- descriptive summaries / 描述性统计
- data visualisation / 数据可视化


### `outputs_from_original_study/`

The synthetic demonstration data differ substantially from the original research dataset and therefore do not reproduce the original statistical distributions or visual patterns.

For this reason, selected **aggregated figures generated from the original study data** are provided separately to demonstrate the intended presentation of the analytical outputs.

由于虚拟演示数据与正式研究数据的分布存在较大差异，因此使用虚拟数据重新生成的图形不能代表原研究的实际结果。

因此，本文件夹单独提供部分**基于原研究数据生成的聚合图表**，用于展示正式分析结果的可视化呈现效果。

No original event-level research data are included in this repository.

**本仓库不包含原研究的事件级原始数据。**

## Data and Confidentiality | 数据与保密说明

The datasets supplied in `sample data/` are synthetic and were created exclusively for demonstrating the code and analytical workflow.

They should not be interpreted as observations from the original study, and analyses performed using these demonstration data are not expected to reproduce the original study findings.

The original event-level research data are not publicly distributed through this repository. Only selected aggregated visual outputs from the original analysis are included.

`sample data/` 中的数据均为专门用于代码及分析流程展示的虚拟数据，不应被理解为原研究中的真实观测数据。使用这些虚拟数据得到的统计结果亦不应被视为对原研究结果的复现。

原研究的事件级数据未通过本仓库公开，仅展示部分原分析产生的聚合可视化结果。
